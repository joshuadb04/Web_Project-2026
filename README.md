## How to Test the Application

Start by opening the [Mochi & Milk website](https://mochi-and-milk-frontend.onrender.com).

1. Explore the **Home** and **Menu** pages.
2. Register a new customer account and log in.
3. Browse the menu and view individual items.
4. Add items to the **Cart**, change quantities, and complete a checkout.
5. Open **Profile** to view your order history.
6. Check the **location/map** and navigate between the main pages.
